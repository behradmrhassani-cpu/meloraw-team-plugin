# متن آماده برای ایجنت: ساخت فایل ایمپورت

این متن را (همراه لیست یا توضیحی که خودت داری) به ایجنتت بده (Claude، Hermes، Gemini و …) تا فایل JSON دقیقاً به فرمت افزونه بسازد. خروجی را در صفحه‌ی «ایمپورت» با «فقط بررسی کن» بیازمای و بعد وارد کن.

> این فایل رمز ندارد و نباید ایجنت هم هیچ رمزی در فایل بگذارد.

---

```
تو دستیار تیم MELORAW هستی. از روی لیست یا توضیحی که می‌دهم، یک فایل JSON برای ایمپورت در تسک‌بورد بساز.

قواعد خروجی (سخت‌گیرانه):
1) فقط JSON خالص بده: بدون توضیح قبل یا بعد، بدون ``` و بدون کامنت. اگر لازم است چیزی را توضیح بدهی،
   در کلید "_help" همان فایل بنویس (کلیدهایی که با _ شروع می‌شوند نادیده گرفته می‌شوند).
2) ساختار:
   {"format":"meloraw-tasks-import","version":1,"tasks":[…],"routines":[…],"ideas":[…]}
   بخشی که ردیف ندارد را حذف کن یا [] بگذار. کلید دیگری نساز: فیلد ناشناخته ردیف را رد می‌کند.
3) مقدارها را فقط از فهرست مجاز بردار:
   status: open | in_progress | done            (پیش‌فرض open)
   bucket: blocker | boost | normal             (پیش‌فرض normal)
   priority: high | med | low                   (پیش‌فرض med)
   owner و هر عضو assignees: you | maral | chakra | auto
   tasks[].kind: phase | new                    (پیش‌فرض new)
   routines[].frequency: daily | weekly | monthly
4) فیلدها:
   tasks: id?، title (اجباری)، description، owner (اجباری)، assignees (فهرست)، status، bucket، priority، kind،
          estimate_minutes (عدد صحیح ≥ 5، دقیقه)، due_date، done_criteria
   routines: id?، title (اجباری)، description، owner (اجباری)، assignees، frequency (اجباری)، status، bucket، priority،
          estimate_minutes، due_date، done_criteria، recurrence_until
   ideas: id?، title (اجباری)، description، type (مثلاً track یا sfx)، category، tag، status
5) تاریخ‌ها میلادی و به شکل YYYY-MM-DD و به وقت UTC. تاریخ شمسی ننویس. اگر تاریخی معلوم نیست، کلید را حذف کن
   یا null بگذار؛ تاریخ حدسی نساز.
6) estimate_minutes را فقط وقتی بنویس که از متن معلوم یا معقول است (حداقل 5). مطمئن نیستی؟ حذفش کن
   (تسک «ناقص» وارد می‌شود و بعداً کامل می‌شود). done_criteria حداکثر 2000 نویسه، description حداکثر 20000.
7) id اختیاری است؛ اگر می‌گذاری کوتاه و یکتا باشد (حروف انگلیسی، عدد، . _ -). کد تسک (مثل MH-1) را خودت نساز؛
   سیستم می‌سازد.
8) هیچ رمز، توکن، Application Password، کلید API، ایمیل یا اطلاعات شخصی داخل فایل نگذار.
9) عنوان‌ها و متن‌ها را همان‌طور که من گفتم بنویس؛ چیزی از خودت اضافه نکن. اگر موردی مبهم بود، به‌جای حدس، از من بپرس.
10) در پایان فایل را یک‌بار بازخوانی کن: JSON معتبر باشد، همه‌ی مقدارها از فهرست مجاز باشند، تعداد ردیف‌ها با لیست من
    بخواند.

نمونه‌ی یک ردیف تسک:
{"title":"نوشتن متن معرفی","owner":"you","assignees":["maral"],"priority":"high","estimate_minutes":45,"due_date":"2030-01-15","done_criteria":"متن تأییدشده"}

لیست / توضیح من:
<اینجا لیست یا توضیحت را بگذار>
```

## بعد از گرفتن فایل
1. در پنل: تسک‌های تیم ← ایمپورت ← فایل را انتخاب کن ← «فقط بررسی کن». خطاها با شماره‌ی ردیف می‌آیند؛ آن‌ها را به ایجنت برگردان تا اصلاح کند.
2. وقتی خطایی نبود، بدون تیک «فقط بررسی کن» وارد کن.
3. ایجنت می‌تواند فهرست زنده‌ی فیلدها را هم بخواند: `GET /schema` (با Application Password خودش).
