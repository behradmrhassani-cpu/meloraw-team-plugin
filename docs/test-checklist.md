# چک‌لیست تست از صفر تا صد

برای یک نفر غیرفنی، روی سایت **خام** (هیچ تسک، روتین یا ایده‌ای نیست). قدم‌ها را به ترتیب برو؛ زیر هر قدم «نتیجه‌ی مورد انتظار» هست. اگر نتیجه فرق کرد، به بخش «اگر نشد» همان قدم و بعد جدول آخر نگاه کن. همه‌ی داده‌های این چک‌لیست ساختگی‌اند و در پایان پاک می‌شوند.

> **رمزها:** هیچ رمزی در این فایل نیست. Application Password را فقط در محیط خودت بگذار (`export MLT_AUTH='کاربر:رمز'`) و در چت، لاگ یا گیت نگذار.
> **تلگرام:** هیچ پیامی خودکار نمی‌رود. برای تست فقط از یک **گروه آزمایشی** استفاده کن، نه گروه اصلی تیم.

نکته‌ی بودجه: هر کاربر در دقیقه ۱۲۰ درخواست API دارد (کارهای پنل هم حساب می‌شوند). اگر پیام «تعداد درخواست‌ها بیش از حد مجاز است» دیدی، همان‌قدر که نوشته صبر کن و ادامه بده.

## ۰) آماده‌سازی
- سه ادمین وردپرس: محمد، مارال، چاکرا (هر کدام نقش Administrator).
- هر نفر در «پروفایل ← Application Passwords» برای ایجنت خودش یک رمز بسازد؛ **نام رمز باید با `Claude-` یا `Hermes-` شروع شود** (مثل `Claude-mh`). رمز فقط یک‌بار نشان داده می‌شود؛ جای امن نگهش دار.
- در ترمینال (سایت واقعی یا آزمایشی خودت):
  ```bash
  export MLT_BASE='https://example.com/wp-json/meloraw-tasks/v1'
  export MLT_AUTH='کاربر:رمز-application-password'   # از محیط امن خودت
  ```

## ۱) نصب
1. پوشه‌ی افزونه را فقط با فایل‌های لازم (`meloraw-team-plugin.php`، `uninstall.php`، `includes/`، `assets/`) در `wp-content/plugins/meloraw-team-tasks/` بگذار.
2. «افزونه‌ها» ← فعال کن.

**انتظار:** منوی «تسک‌های تیم» در ستون کنار وردپرس پیدا می‌شود؛ زیرمنوها: برد، امروز من، زمان و امتیاز، روتین‌ها، بانک ایده‌ها، گزارش‌ها، لاگ، ایمپورت، تنظیمات، بررسی سلامت. برد خالی است («تسکی نیست.»). بالای هر صفحه نوار تاریخ و ساعت UTC هست و بنر «چرا زمان کارهامون رو ثبت می‌کنیم؟».

**اگر نشد:** منو نیست → کاربر Administrator نیست یا افزونه فعال نشده. «خطای مرگبار» → نسخه‌ی PHP (حداقل ۷.۴).

## ۲) تنظیمات
«تسک‌های تیم ← تنظیمات»:
1. **هویت اعضا:** هر حساب را به عضوش وصل کن (محمد ← محمد (MH)، مارال ← مارال (MA)، چاکرا ← چاکرا (CH)). حساب اتوماسیون، اگر داری، ← اتوماسیون (AU). ذخیره.
2. **تلگرام** (اختیاری): توکن ربات و chat id **گروه آزمایشی**. ذخیره. (بهتر: ثابت‌های `MLT_TELEGRAM_*` در `wp-config.php`.)
3. **ساعت اوج انرژی:** برای هر نفر یک ساعت UTC.
4. **اعلان سراسری** (اختیاری): یک متن کوتاه + فعال.

**انتظار:** «تنظیمات ذخیره شد.». فیلد توکن بعد از ذخیره خالی است و فقط می‌نویسد «ذخیره شده است». هر نفر بالای برد، کلید «تسک‌های من / همه» را می‌بیند. اعلان (اگر گذاشتی) بالای همه‌ی صفحه‌ها برای همه دیده می‌شود. در ساعت اوج یک پیام «⚡ الان ساعت اوج انرژی توست» بالای صفحه‌ها می‌آید.

**اگر نشد:** «قالب توکن درست نیست» → باید مثل `123456789:ABC…` باشد. کلید «تسک‌های من/همه» نیست → حسابت وصل نشده؛ زیر «هویت اعضا» ببین.

## ۳) بررسی سلامت
«بررسی سلامت» را باز کن.

**انتظار:** ۱۳ کارت. سبز لازم: جدول‌ها و schema، PHP، MySQL/MariaDB، InnoDB و JSON، Application Passwords، هدر Authorization، هدرهای امنیتی، ساعت و UTC، نگاشت حساب‌ها (بعد از قدم ۲). HTTPS روی سایت واقعی سبز است. تلگرام: سبز اگر تنظیم کردی، وگرنه زرد. شمارنده‌ها: زرد «هنوز هیچ تسک…». رمزهای ایجنت‌ها: نام‌ها دیده می‌شود (خودِ رمز هرگز).
هر کارتِ زرد یا قرمز زیرش «راه حل» دارد؛ همان را انجام بده و «اجرای دوباره» را بزن.

**پیام آزمایشی تلگرام:** «ارسال پیام آزمایشی» را بزن و تأیید کن. **انتظار:** در گروه آزمایشی یک پیام با 🧪 می‌آید؛ در صفحه «پیام آزمایشی ارسال شد» و در «لاگ» یک ردیف «ارسال به تلگرام». اگر خطا بود، دلیل کوتاه فارسی می‌آید (مثل «توکن ربات نامعتبر است») و در لاگ «خطای تلگرام» ثبت می‌شود (بدون توکن).

## ۴) ایمپورت قالب نمونه، اول با «فقط بررسی»
1. «ایمپورت ← دانلود قالب ← کامل ← قالب نمونه‌دار».
2. فایل را انتخاب کن، تیک «فقط بررسی کن، چیزی ذخیره نشود» را بزن، «شروع ایمپورت».

**انتظار:** «نتیجه‌ی بررسی (چیزی ذخیره نشد)»؛ تسک‌ها ۳، روتین‌ها ۳، ایده‌ها ۳ «ساخته می‌شد»؛ تکراری ۰؛ نامعتبر ۰. برد همچنان خالی است.

**تمرین خطا (اختیاری):** در یک کپی از فایل، `"owner": "you"` یکی را به `"owner": "x"` تغییر بده و دوباره «فقط بررسی کن». **انتظار:** یک ردیف نامعتبر با «ردیف N» و دلیل فارسی («مقدار owner نامعتبر است…») و بقیه سالم.

## ۵) ایمپورت واقعی
همان فایل، **بدون** تیک. **انتظار:** تسک‌ها ۳، روتین‌ها ۳، ایده‌ها ۳ «ساخته شد». برد: تسک‌های نمونه با کد (`MH-1`، `CH-1`، `MA-1`)، سررسید، تخمین و معیار انجام. «روتین‌ها» سه روتین (روزانه، هفتگی، ماهانه) و «بانک ایده‌ها» سه ایده. دوباره همان فایل را وارد کن: همه «تکراری» و چیزی اضافه نمی‌شود. «بررسی سلامت ← شمارنده‌ها»: ۳ تسک، ۳ روتین، ۳ ایده.

## ۶) ساخت تسک دستی
برد ← «+ افزودن تسک»: عنوان «تست دستی ۱»، مسئول اصلی خودت، **زمان تقریبی ۳۰** (اجباری)، اولویت بالا، یک سررسید، ذخیره.
**انتظار:** پیام «تسک «تست دستی ۱» ساخته شد.»؛ کارت با کد پیوسته (مثل `MH-4`) و دکمه‌ی کپی کد. بدون زمان تقریبی فرم ذخیره نمی‌شود.

## ۷) ساخت تسک با API
```bash
curl -s -u "$MLT_AUTH" -H 'Content-Type: application/json' -X POST "$MLT_BASE/tasks" \
  -d '{"title":"تست API ۱","owner":"you","estimate_minutes":20,"priority":"med","assignees":["maral"]}'
curl -s -u "$MLT_AUTH" "$MLT_BASE/tasks/MH-5"      # با کد تسک (کدی که پاسخ بالا داد)
curl -s "$MLT_BASE/tasks"                           # بدون رمز
```
**انتظار:** اولی ۲۰۱ با `code` (پیشوند از هویت **سازنده**: MH/MA/CH؛ اگر حسابت در «هویت اعضا» وصل نشده، `AU-`؛ ایمپورت پیشوند را از مسئول اصلی می‌گیرد) و `assignees: ["you","maral"]`؛ دومی همان تسک؛ سومی ۴۰۱ با پیام کلی «دسترسی ندارید.». بدون `estimate_minutes` خطای ۴۰۰ فارسی. کاربر مارال تسک را در «تسک‌های من» خودش هم می‌بیند.
**اگر ۴۰۱ با رمز درست:** «بررسی سلامت ← Authorization» را ببین (docs/cache-exclusions.md).

## ۸) تغییر وضعیت
روی کارت «تست دستی ۱» از select وضعیت «در حال انجام» را انتخاب کن.
**انتظار:** کارت به ستون «در حال انجام» می‌رود و در «لاگ» «تغییر وضعیت» با نام تو ثبت می‌شود. هیچ پیام تلگرامی نمی‌رود.

## ۹) کامنت و پرچم
«کامنت‌ها (۰)» ← یک متن ساده ← «ثبت کامنت». کنار کامنت «پرچم».
**انتظار:** کامنت با نام و ساعت UTC؛ بعد از پرچم، حاشیه‌ی طلایی و «پرچم‌دار». «گزارش‌ها» همان کامنت را نشان می‌دهد؛ «تبدیل به تسک» یک تسک تازه می‌سازد (بدون زمان تقریبی → «ناقص») و پرچم برداشته می‌شود.

## ۱۰) تایمر، پاز و پایان
1. روی کارت «تست دستی ۱» «▶ شروع». **انتظار:** نوار تایمر بالای صفحه با کد و شمارنده‌ی زنده؛ دکمه‌ی «شروع» روی کارت‌های دیگر غیرفعال.
2. در نوار، دلیل پاز (مثلاً «غذا») را انتخاب کن و «پاز». (بدون دلیل نمی‌شود؛ کنار انتخاب «؟» می‌گوید چرا می‌پرسیم.) **انتظار:** نوار «⏸ پاز».
3. «ادامه»، چند ثانیه صبر، «پایان تایمر». **انتظار:** نوار ناپدید می‌شود.
4. «زمان و امتیاز»: زمان خالص، زمان پاز، تعداد پاز (۱) و پاز «غذا».

## ۱۱) امتیاز
وضعیت «تست دستی ۱» را روی «انجام‌شده» بگذار (اگر معیار انجام دارد، تأییدش را می‌پرسد؛ اگر سررسید گذشته، دلیل دیرکرد اختیاری را).
**انتظار:** کارت در «انجام‌شده» با برچسب `+۳۰` (اولویت بالا × ۱۰ چون زمان خالص کمتر از تخمین است). «زمان و امتیاز» امتیاز هفته را نشان می‌دهد. تسکی که تایمر نداشت و done شد برچسب «بدون زمان‌سنج» و امتیاز ۰ می‌گیرد.

## ۱۲) «امروز من»
**انتظار:** تسک‌های باز خودت به ترتیب (دیرشده/سررسید امروز، اولویت بالا، در حال انجام)؛ حداکثر سه تسک اول زیر «تمرکز اصلی (۸۰٪)» و بقیه زیر «بقیه (۲۰٪)». تسک‌های دیگران و انجام‌شده‌ها نیستند.

## ۱۳) تحویل به ایجنت
روی یک کارت «📋 تحویل به ایجنت» ← «کپی متن».
**انتظار:** متن شامل کد، عنوان، شرح، معیار انجام، مسئول‌ها، اولویت، سررسید، زمان تقریبی، آدرس API و مراحل (گرفتن تسک، شروع تایمر، کامنت، وضعیت، پایان تایمر). **هیچ رمز یا توکنی** در آن نیست.

## ۱۴) تلگرام دستی
1. روی فرم کامنت یا وضعیت تیک «📣 ارسال به تلگرام» را بزن. **انتظار:** یک متن ویرایش‌پذیر باز می‌شود (عنوان، مسئول، وضعیت، فرستنده، لینک). متن را ویرایش کن و ذخیره کن. **انتظار:** فقط همان متن به گروه آزمایشی می‌رود؛ بدون تیک هیچ‌چیز نمی‌رود.
2. پیام مستقل:
   ```bash
   curl -s -u "$MLT_AUTH" -H 'Content-Type: application/json' -X POST "$MLT_BASE/notify" -d '{"text":"تست دستی"}'
   ```
   **انتظار:** `{"sent":true}` و پیام در گروه آزمایشی. اگر تلگرام تنظیم نشده: ۴۰۹ با «توکن یا chat id … کامل نیست».
3. اگر تلگرام در دسترس نباشد، تغییر (کامنت یا وضعیت) ذخیره می‌شود و بالای صفحه هشدار فارسی می‌آید؛ در «لاگ» «خطای تلگرام» بدون توکن.

## ۱۵) روتین‌ها
«روتین‌ها»: روتین روزانه را «انجام‌شده» کن. **انتظار:** فقط وضعیت همین روز عوض می‌شود. «قالب روتین» ← زمان تقریبی ← ذخیره؛ «متوقف کردن روتین» ← به بخش «متوقف‌شده» می‌رود و فرم وضعیت ندارد؛ «ادامه‌ی روتین» برمی‌گرداند. فردا (UTC) روتین خودش از نو شروع می‌شود.

## ۱۶) لاگ
«لاگ» را باز کن. **انتظار:** ردیف‌های ایمپورت، ساخت تسک، تغییر وضعیت، کامنت، پرچم، تبدیل به تسک، شروع/پاز/ادامه/پایان تایمر، امتیاز، تلگرام (در صورت استفاده) با نام درست کاربر (و نام ایجنت اگر از API بود). هیچ توکن یا متن کامنت و پیام تلگرام در لاگ نیست. فیلتر کاربر/عمل/تاریخ کار می‌کند.

## ۱۷) export
```bash
curl -s -u "$MLT_AUTH" "$MLT_BASE/export" > backup.json
```
**انتظار:** JSON با `tasks` و `comments`؛ بدون هیچ رمز یا تنظیماتی. (زمان‌سنج، تمدید و امتیاز در export نیست؛ برای بکاپ کامل از دیتابیس هم نسخه بگیر.)

## ۱۸) حذف تسک‌های تستی
هر کارت ← «حذف» ← تأیید (تسک، کامنت‌ها، زمان‌ها و امتیازش پاک می‌شود). تسک‌های نمونه‌ی ایمپورت و روتین‌ها را هم با API پاک کن (یا اگر خواستی، همه‌چیز را با گزینه‌ی «حذف داده‌ها هنگام حذف افزونه» و حذف افزونه).
**انتظار:** «بررسی سلامت ← شمارنده‌ها» به صفر برمی‌گردد.

## اگر نشد: خطاهای رایج
| نشانه | علت | راه حل |
|---|---|---|
| همیشه ۴۰۱ با رمز درست | هدر Authorization حذف می‌شود | «بررسی سلامت» (کارت Authorization)؛ قاعده‌ی `.htaccess` همان‌جا |
| ۴۰۳ روی `/wp/v2/...` با رمز `Claude-…` | عمدی است: این رمزها فقط روی API این افزونه کار می‌کنند | رمز دیگری (با اسم دیگر) برای کار دیگر بساز |
| ۴۰۹ «حساب شما… نگاشت نشده» (فقط برای «تسک‌های من»، `?mine=1`) | هویت وصل نشده | تنظیمات ← هویت اعضا |
| ۴۲۹ | بیش از ۱۲۰ درخواست در دقیقه | به `Retry-After` صبر کن |
| پیام تلگرام نرفت و «مهلت پاسخ تمام شد» | سرور به تلگرام دسترسی ندارد (فیلتر) | از «بررسی سلامت» دوباره امتحان کن؛ از هاست خروجی HTTPS به api.telegram.org بخواه |
| «تکراری» برای همه‌ی ردیف‌ها | قبلاً وارد شده | عمدی است؛ عنوان یا `id` را عوض کن |
| دکمه‌ها در هاور ناخوانا | CSS ادمین وردپرس | `python3 tests/css-check.py` و `node tests/css-states.js` |
| صفحه‌ی ادمین قدیمی نشان داده می‌شود | کش | docs/cache-exclusions.md |
